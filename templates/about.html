Project Overview & Abstract

Course Code: AGA-701

Shortest Path Finder Using Graph Algorithms

Abstract: In computer science and discrete mathematics, determining the most efficient route between nodes in a network topology represents a foundational optimization challenge. This full-stack web application is developed as a comprehensive educational and analytical system for the B.Tech Computer Science Advanced Graph Algorithms (AGA) curriculum. It provides interactive graph topology modeling using Cytoscape.js, step-by-step visual animation of algorithm internal states, empirical runtime performance benchmarking using Chart.js, and persistent search histories backed by SQLite. Custom modular Python implementations of five core graph algorithms—Dijkstra, Bellman-Ford, Floyd-Warshall, Breadth-First Search (BFS), and Depth-First Search (DFS)—are evaluated against variable graph constraints including directed, undirected, non-negative, and negative-weight topologies.

Department: Computer Science & Engineering
Domain: Advanced Graph Algorithms & Web Engineering
Backend Stack: Python 3.11, Flask, SQLite3, Werkzeug
Frontend Stack: HTML5, CSS3, ES6 JavaScript, Cytoscape.js, Chart.js

Problem Statement & Motivation

Traditional algorithm pedagogy frequently relies upon static textbook diagrams and theoretical pseudo-code. Students and engineers often struggle to develop an intuitive mental model of dynamic edge relaxation, priority queue state transitions, negative cycle detection mechanics, and all-pairs matrix progressions.

Furthermore, arbitrary unweighted traversals like BFS are often conflated with weighted shortest-path optimization. This project addresses these educational challenges by creating an interactive, transparent sandbox where every relaxation step is logged, explained, and rendered visually from genuine backend Python execution traces.

Core Project Objectives

  • Implement five core graph algorithms in pure Python without external graph-theory wrappers.
  • Build an interactive Cytoscape.js canvas supporting live vertex insertion, deletion, edge weighting, and repositioning.
  • Generate granular execution trace arrays on the backend to drive animated step-by-step visualizations.
  • Provide comparative empirical benchmarks measuring CPU execution time, node visit counts, and edge relaxations.
  • Maintain isolated user sessions, credential hashing with Werkzeug, and SQLite storage for topologies and search histories.

Graph Representations & Theoretical Foundations

Vertices (V) and Edges (E)

A graph G = (V, E) consists of a set of vertices V representing entities (e.g. routers, intersections) and edges E ⊆ V × V representing relationships or channels connecting vertex pairs.

Directed vs. Undirected

In a directed graph (digraph), edges possess an orientation: (u, v) ≠ (v, u). In undirected graphs, edges are bidirectional, permitting symmetric traversal between adjacent nodes.

Weighted vs. Unweighted

Weighted graphs assign a numerical scalar w(u, v) representing latency, distance, or financial cost. Unweighted graphs treat every edge as possessing equal unit cost 1.

Adjacency List vs. Matrix

This application utilizes adjacency lists O(V + E) space for sparse algorithmic traversals, and dynamic 2D distance matrices O(V²) space for Floyd-Warshall all-pairs computation.

Algorithm Implementations & Mechanics

1. Dijkstra's Algorithm (Greedy Single-Source Shortest Path)

Concept: Discovered by Edsger W. Dijkstra in 1956. Uses a min-priority queue (implemented via Python's heapq) to repeatedly extract the unvisited vertex with minimum tentative distance and relax its outgoing incident edges.
Key Invariant: Assumes that the shortest path to an extracted vertex cannot be improved by future explorations. Therefore, it requires strictly non-negative edge weights (w(u, v) ≥ 0). If a negative weight is detected, our implementation immediately rejects the query with an educational alert directing the user to Bellman-Ford.
Time Complexity: O((V + E) log V) using a binary heap; Space Complexity: O(V).

2. Bellman-Ford Algorithm (Dynamic Programming with Negative Weight Support)

Concept: Formulated by Richard Bellman and Lester Ford Jr. in 1958. Relaxes all edges in the graph across |V| - 1 consecutive passes. A simple shortest path in a graph of |V| vertices can contain at most |V| - 1 edges, ensuring convergence if no negative cycles exist.
Negative-Weight Cycle Detection: On pass |V|, if any edge can still be relaxed, the algorithm proves the existence of a negative-weight cycle reachable from the source. The implementation traces and isolates the cycle vertices, warning the user that an optimal minimum path is mathematically undefined.
Time Complexity: O(V · E); Space Complexity: O(V).

3. Floyd-Warshall Algorithm (All-Pairs Dynamic Programming)

Concept: Published by Robert Floyd and Stephen Warshall in 1962. Operates on a distance matrix D. It systematically considers every vertex k ∈ V as an intermediate pivot and evaluates whether D[i][k] + D[k][j] < D[i][j].
Reconstruction: Tracks a parallel predecessor/next-hop matrix next_node[i][j] to reconstruct the exact path between any chosen source and destination. Detects negative cycles if any diagonal entry D[i][i] < 0.
Time Complexity: O(V³); Space Complexity: O(V²).

4. Breadth-First Search (BFS)

Concept: Traverses graphs radially level-by-level utilizing a first-in, first-out (FIFO) queue (collections.deque).
Shortest Path Guarantee: BFS strictly guarantees the shortest path in terms of the minimum number of edge hops on unweighted graphs. On weighted graphs, our interface highlights that BFS minimizes hop count rather than total edge weight sum.
Time Complexity: O(V + E); Space Complexity: O(V).

5. Depth-First Search (DFS)

Concept: Explores along each topological branch as deeply as possible before backtracking via an explicit recursion stack.
Important Academic Distinction: DFS is an exhaustive graph traversal mechanism and DOES NOT guarantee a shortest path under any metric. It is included to demonstrate exploration order, discovery timestamps, and stack backtracking.
Time Complexity: O(V + E); Space Complexity: O(V).

Real-World Applications

  • GPS & Mapping Services: Google Maps and OpenStreetMap employ accelerated variants of Dijkstra (e.g. A* search, Contraction Hierarchies) for turn-by-turn road navigation.
  • Internet Routing Protocols: Link-State routing protocols like OSPF (Open Shortest Path First) run Dijkstra, while Distance-Vector protocols like RIP (Routing Information Protocol) utilize Bellman-Ford.
  • Telecommunications & Bandwidth Allocation: Determining minimum latency routes across fiber optic backbones and peer exchange points.
  • Financial Arbitrage: Detecting foreign currency exchange arbitrage cycles by taking negative logarithms of exchange rates and running Bellman-Ford negative-cycle detection.

Future Enhancements

  • Heuristic Algorithms: Incorporation of A* Search with Euclidean and Manhattan spatial heuristics.
  • Spanning Tree Algorithms: Visualization of Kruskal's and Prim's Minimum Spanning Tree (MST) algorithms.
  • Flow Networks: Adding Ford-Fulkerson and Edmonds-Karp Maximum Flow algorithms.
  • Large-Scale Dataset Import: Direct import and export of GIS Shapefiles and OpenStreetMap XML files.
