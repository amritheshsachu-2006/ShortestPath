Theoretical Analysis & Selection Guidelines

1. Dijkstra's Algorithm

Optimal Use: Weighted graphs with strictly non-negative edges.
Mechanism: Greedy selection using a min-priority queue (binary heap).
Limitation: Fails with negative edge weights because greedy commitments cannot be revised.

2. Bellman-Ford Algorithm

Optimal Use: Graphs with negative edge weights or distributed routing (Distance Vector).
Mechanism: Relaxes all edges |V| - 1 times using dynamic programming.
Feature: Detects unreachable and reachable negative-weight cycles on pass |V|.

3. Floyd-Warshall Algorithm

Optimal Use: All-pairs shortest paths in dense graphs with up to a few hundred nodes.
Mechanism: 3-nested loops computing intermediate pivots D(k)[i][j] in O(V³).
Feature: Computes complete all-pairs distance matrix; detects negative cycles via diagonal elements.

4. Breadth-First Search (BFS)

Optimal Use: Unweighted networks or minimum-hop routing (e.g. social networks, web crawler).
Mechanism: Level-by-level queue exploration in linear time O(V + E).
Limitation: Does NOT optimize arbitrary edge weights; minimizes edge hop count only.

5. Depth-First Search (DFS)

Optimal Use: Topological sort, cycle detection, strongly connected components, maze solving.
Mechanism: Stack-based deep branch exploration and backtracking.
Important: DFS is a traversal algorithm and does NOT guarantee a shortest path.
