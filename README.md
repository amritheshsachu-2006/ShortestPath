## 📌 Project Overview
**Shortest Path Finder Using Graph Algorithms** is a full-stack educational and analytical web platform developed for the **B.Tech Computer Science and Engineering (CSE)** curriculum under **Advanced Graph Algorithms (AGA)**.

## 🚀 Key Features

1. **User Authentication & Session Security**:
   - Secure registration, login, and logout.
   - Werkzeug secure password hashing (`scrypt`).
   - SQLite user credentials with username and email uniqueness constraints.
   - Local development password recovery flow.
   - User isolation: saved graphs and search history are strictly private to each student account.

2. **Interactive Graph Editor (Cytoscape.js)**:
   - Add, rename, and delete vertices.
   - Connect vertices with directed or undirected edges.
   - Assign positive, zero, or negative weights.
   - Drag and reposition nodes with real-time layout syncing.
   - Pre-loaded pedagogical sample topologies (Classic 6-node, Negative-Edge DAG, Negative Cycle Demo, Undirected Web, All-Pairs 4-City, Disconnected).
   - Random graph generator with density and negative-weight toggles.
   - Save custom topologies directly to the SQLite database.

3. **Five Custom Pure-Python Graph Algorithms**:
   - **Dijkstra's Algorithm**: Min-priority queue (`heapq`) implementation. Strictly rejects negative weights with clear pedagogical guidance. $O((V + E) \log V)$.
   - **Bellman-Ford Algorithm**: Repeated edge relaxation across $|V| - 1$ passes. Detects, isolates, and traces reachable negative-weight cycles on pass $|V|$. $O(V \cdot E)$.
   - **Floyd-Warshall Algorithm**: Dynamic programming 3D all-pairs distance matrix. Computes shortest paths between all pairs and reconstructs specific paths. $O(V^3)$.
   - **Breadth-First Search (BFS)**: Level-by-level queue traversal (`collections.deque`). Guarantees minimum edge hops on unweighted graphs. $O(V + E)$.
   - **Depth-First Search (DFS)**: Stack-based branch exploration with backtracking. Clarifies traversal order without falsely claiming shortest path optimality. $O(V + E)$.

4. **Step-by-Step Algorithm Animation Engine**:
   - Driven entirely by **real execution traces** generated by the Python backend.
   - Controls: **Play**, **Pause**, **Next Step (▶|)**, **Previous Step (|◀)**, **Reset (↺)**, and **Speed selector (0.5x, 1x, 2x, 5x)**.
   - Dynamic real-time inspector tracking: active vertex, active edge, visited set, unvisited set, tentative distance table / matrix, and human-readable step explanations.

5. **Algorithm Comparison Benchmark**:
   - Executes all 5 algorithms simultaneously on the active topology.
   - High-precision CPU timing using `time.perf_counter()`.
   - Side-by-side metric table and dual interactive **Chart.js** bar charts (Execution Time in ms and Operations/Relaxations count).

6. **Search History**:
   - Automatically logs search queries, calculated paths, distances, execution times, and timestamps into SQLite.
   - Provides a one-click "Replay" action to load past searches directly into the step-by-step visualizer.

## 📊 Asymptotic Complexity Matrix

| Algorithm | Time Complexity | Space Complexity | Weight Support | Optimality Guarantee |
| :--- | :--- | :--- | :--- | :--- |
| **Dijkstra** | $O((V + E) \log V)$ | $O(V)$ | Non-negative only ($\ge 0$) | Guaranteed optimal shortest path |
| **Bellman-Ford** | $O(V \cdot E)$ | $O(V)$ | Negative & Positive | Optimal; detects negative cycles |
| **Floyd-Warshall** | $O(V^3)$ | $O(V^2)$ | Negative & Positive | All-pairs optimal; detects diagonal cycles |
| **BFS** | $O(V + E)$ | $O(V)$ | Unweighted | Guaranteed minimum number of hops |
| **DFS** | $O(V + E)$ | $O(V)$ | Unweighted / Traversal | Valid route discovery; no optimality guarantee |
